# Bashcrawl documentation

> Every document in this repository, one line each — start with the root README to play, AGENTS.md to work on the code, and the guides below for depth.

New to the game? Read [getting-started.md](getting-started.md), then [gameplay.md](gameplay.md). Authoring rooms or courses? Start with [contributing.md](contributing.md) and [authoring-courses.md](authoring-courses.md). Working on the engine or the web app? [PLATFORM.md](PLATFORM.md) has the layers and [ARCHITECTURE.md](ARCHITECTURE.md) every component. Pages under `generated/` are rebuilt by `make generate-contract-docs`; never edit them by hand.

**Backlog of record:** GitHub Issues with the fleet labels.
