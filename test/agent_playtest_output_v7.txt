~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
🎓 Understanding Shell Aliases
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This is known as a **shell alias** or **command alias**. With this alias active:

• Typing simply `ls` by itself will automatically run `ls -F`
• Your spell becomes permanently enhanced for this terminal session  
• The magic persists until you close your terminal or create a new alias

Items that end with * when you run  ls -F  are executable

################################################################################
#                     ⚡ RUNNING EXECUTABLES                                  #
################################################################################

To activate an executable, use the dot-slash incantation:

    ./treasure        Activate the treasure chest
    ./potion          Consume a magickal potion

THE DOT-SLASH EXPLAINED:
    .   = "right here" (current directory)
    /   = path separator
    ./  = "run the thing HERE, not some other command"

Without the dot-slash, the shell looks for system commands
instead of local files.  Always use  ./  for local scripts.

--------------------------------------------------------------------------------
⚡ RELATIVE vs ABSOLUTE PATHS
--------------------------------------------------------------------------------

RELATIVE PATHS (from where you stand):

    ./treasure           Item in THIS room
    ../treasure          Item in the room ABOVE
    chamber/spell        Item in the chamber below

ABSOLUTE PATHS (from the root of the world):

    /usr/bin/ls          System command at exact location
    ~/documents/file     File in your home territory

--------------------------------------------------------------------------------
⚡ PERMISSIONS: chmod
--------------------------------------------------------------------------------

Some items need permission before you can wield them.
The chmod spell grants execution power:

    chmod +x item        Make an item executable
    ls -l item           Inspect an item's permissions

READING PERMISSIONS:
    -rwxr-xr-x   The 'x' means executable
    -rw-r--r--   No 'x' means NOT executable

┌─────────────────────────────────────────────────────────────────────────────┐
│ PERMISSION REFERENCE                                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ COMMAND              │ PURPOSE                                             │
│ ls -l                │ Show detailed permissions for all files             │
│ ls -F                │ Show type indicators (* = executable)               │
│ chmod +x FILE        │ Grant execution permission                         │
│ cat FILE             │ Read a script before running it                     │
│ file FILE            │ Identify what type of file something is             │
└─────────────────────────────────────────────────────────────────────────────┘

################################################################################
#                    🔍 SEARCHING FILES: grep                                 #
################################################################################

The grep spell searches for a word inside a file:

    grep WORD FILENAME

Try searching this very scroll for the word "treasure":

    grep treasure scroll

grep only shows lines that MATCH your search term.
This is invaluable when dealing with long files.

    grep "executable" scroll     Find lines about executables
    grep -i "COMBAT" scroll      Case-insensitive search

ANCIENT WISDOM: The Power of Memory
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You stand in a vast underground chamber lit by flickering
blue torchlight.  Runes carved into the walls pulse with
an otherworldly energy.  This is where adventurers learn
the art of MEMORY — the ability to store and recall
knowledge using the power of variables.

################################################################################
#                     📜 ENVIRONMENT VARIABLES                                #
################################################################################

In these catacombs, your memories are stored as VARIABLES.
A variable is a named container that holds a value.

--------------------------------------------------------------------------------
⚡ CREATING VARIABLES: export
--------------------------------------------------------------------------------

The export spell binds a value to a name, making it
available throughout your adventure:

    export HP=15

This creates a variable called HP with the value 15.

┌─────────────────────────────────────────────────────────────────────────────┐
│ VARIABLE REFERENCE                                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ COMMAND               │ PURPOSE              │ EXAMPLE                     │
│ export VAR=value      │ Create a variable    │ export HP=15                │
│ echo $VAR             │ Read a variable      │ echo $HP                    │
│ export I=item,$I      │ Append to variable   │ export I=sword,$I           │
│ let "VAR=VAR-5"       │ Do arithmetic        │ let "HP=HP-5"               │
│ unset VAR             │ Forget a variable    │ unset HP                    │
└─────────────────────────────────────────────────────────────────────────────┘

--------------------------------------------------------------------------------
⚡ READING VARIABLES: echo
--------------------------------------------------------------------------------

The echo spell speaks aloud whatever you tell it.
When you prefix a variable name with $, echo reveals
its contents:

    echo $HP
    echo $I

Try it now:

    echo $HP

If nothing appears, you haven't set your HP yet!
Go back to the armoury and drink the potion first.

--------------------------------------------------------------------------------
⚡ YOUR INVENTORY: $I
--------------------------------------------------------------------------------

Your inventory is stored in the variable I (for Inventory).
Each treasure you collect gets added with a comma:

    export I=coins,$I

To check what you're carrying:

    echo $I

You should see items like:  sword,amulet,

If your inventory is empty, you may have missed treasures
in earlier rooms.  Use cd .. to retrace your steps.

--------------------------------------------------------------------------------
⚡ ARITHMETIC: let
--------------------------------------------------------------------------------

The let spell performs calculations on your variables:

    let "HP=HP-5"       Subtract 5 from HP
    let "HP=HP+10"      Add 10 to HP
    let "HP=HP*2"       Double your HP

After arithmetic, check the result:

    echo $HP

The runes are instructions on how to summon a PORTAL — a
magickal shortcut to a distant room.

In the terminal, this is called a SYMBOLIC LINK (symlink).
A symlink is a special file that points to another location,
like a portal that teleports you somewhere else.

The command to create one is:

    ln -s TARGET LINKNAME

  TARGET   = where the portal LEADS (the destination)
  LINKNAME = what you call the portal here

To create a portal from this chamber to the hall:

    ln -fs ../../../chapel/courtyard/aviary/hall portal

Once created, walk through it like any other door:

    cd portal

To learn more about symlinks, visit the SCRAP room
(accessible from the entrance).

────────────────────────────────────────────────────────────────────────────────
⚡ THE ART OF CRAFTING SPELLS: Shell Functions
────────────────────────────────────────────────────────────────────────────────

In the terminal, you can CREATE your own commands using
shell functions.  A function is a named block of commands
that you can call by name, just like a built-in spell.

The syntax is:

    function_name () {
        command1
        command2
    }

For example, to create a command called 'inventory' that
shows your items:

    inventory () { echo $I; }

After defining it, just type:

    inventory

And your inventory is displayed!

────────────────────────────────────────────────────────────────────────────────
⚡ CREATING THE BASHCRAWL COMMAND: bc
────────────────────────────────────────────────────────────────────────────────

The diagrams on the wall describe a powerful meta-spell — a
command called 'bc' that summons the Bashcrawl help system
from anywhere in the dungeon.

To create it, speak these words:

    bc () { bash $BASHCRAWL_ROOT/help.sh "$@"; }
    export -f bc

Now you can use it from any room:

    bc              Show contextual help for your location
    bc commands     Show the full command reference
    bc map          Show the dungeon map

But wait — this spell will fade when you close the terminal.
To make it permanent, inscribe it into your personal scroll
of incantations:

    echo 'bc () { bash $BASHCRAWL_ROOT/help.sh "$@"; }' >> ~/.bashrc

┌─────────────────────────────────────────────────────────────────────────────┐
│ FUNCTION vs ALIAS                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│  alias    │ Simple text substitution  │ alias ll='ls -la'                  │
│  function │ Full logic + arguments    │ greet () { echo "Hello $1"; }      │
│           │                           │                                     │
│  Use aliases for shortcuts.  Use functions when you need                    │
│  arguments ($1, $2, ...) or complex logic (if/then/loops).                 │

--------------------------------------------------------------------------------
                     SYMLINK SPELL: ln -s
--------------------------------------------------------------------------------

A symlink is a magickal portal — a shortcut that points
to another location without moving the original.

CREATING A PORTAL:

    ln -s TARGET LINK_NAME

EXAMPLE — Create a portal to a hidden rift:

    From the entrance:
        ln -s .rift portal

    From the chamber:
        ln -s ../../../../.rift portal

Once created, you can walk through the portal:

    cd portal

NOTE: The portal points to where something IS, not where
you want it to BE.  If the target path is wrong, the portal
leads nowhere.

CHECK IF SOMETHING IS A PORTAL:

    ls -l

    Symlinks appear as:  portal -> .rift

REMOVE A PORTAL:

    rm portal

    This removes the link, NOT the destination!
