# The Reference door fits the window: search, chips, cards and footer — evidence

> **Feature:** `BASHCRAWL-014` · **Scenario:** `verify/scenarios/reference-fit.yml` · **Result:** **PASS** (3/3 viewports, 9 steps each, no console errors) · **Generated by:** `node verify/runner.mjs --by agent` against the production bundle (`make web-bundle`, served by `npm run preview` as `verify/verify.yml` says), 2026-11-20 (UTC)

A returning hero opens the Reference door and everything in it fits the window at all three sizes. The scenario was written as the reproduction of a defect and failed 0/3 on its first run: on a phone the door laid out 427 px wide whatever the window (a category chip that could not wrap set the width of an unconstrained grid column, and the shell clipped the rest), and at 1280×800 the shell's footer was pushed below the window. Both are fixed: every screen's grid column is `minmax(0, 1fr)`, the chips wrap, the table's rows stack on a phone, and each part of the shell keeps its own grid row whether or not the status strip and the prompt dock are present.
