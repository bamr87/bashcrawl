# The home page routes a newcomer, a returning hero and a door link — evidence

> **Feature:** `BASHCRAWL-028` · **Scenario:** `verify/scenarios/home-first-run.yml` · **Result:** **PASS** (2/2 viewports, 46 steps each, no console errors, nothing cut off sideways) · **Generated by:** `node verify/runner.mjs --by agent` against the production bundle (`make web-bundle`, served by `npm run preview` as `verify/verify.yml` says), 2026-11-20 (UTC)

The paths around the home page that `home-page.yml` does not walk. A first-time visitor types all four suggested commands into the sandbox: the log grows to 101 lines, holds `/entrance $ pwd`, `cellar/` and `Moved to /entrance/cellar`, the prompt becomes `/entrance/cellar $`, and `localStorage` stays empty (no save, no hero). "Start playing" opens the "Create your hero" dialog on its first step. A returning hero whose last door was the Arcade opens the same address and lands on `#/arcade` with the five game cards; the brand button takes them to `#/home`, where the call to action reads "Continue as Mira". A newcomer who opens `#/story` directly gets the title screen (New game · How to play · Options) and no home page.
