# The Arcade and Reference doors open with an ASCII Motion clip — evidence

> **Feature:** `BASHCRAWL-025` · **Scenario:** `verify/scenarios/door-art.yml` · **Result:** **PASS** (2/2 viewports, 24 steps each, no console errors, no sideways scroll) · **Generated by:** `node verify/runner.mjs --by agent` against the production bundle (`make web-bundle`, served by `npm run preview` as `verify/verify.yml` says), 2026-11-20 (UTC)

A returning hero switches between the Practice Arcade and the Reference door in both themes. Each switch mounts the door's header fresh: `<ArtClip name="door-arcade">` in the Arcade floor's header and `<ArtClip name="door-reference">` beside the Reference search. Each plays its ASCII Motion clip (`motion/art/door-*.asciimtn`, registered in `src/help/data/motion.yaml`) once and rests on its last frame. The scenario samples each header for 2.4 s after the switch: the Arcade clip painted 6 distinct frames and the Reference clip 9, in both themes and at both widths, and neither was still playing afterwards (`report.json`, the `*-plays-once` evals).
